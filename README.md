# Wassel

Live delivery tracking: customer app and courier app with maps, real-time courier position, accurate ETA and geofencing.

- Brand color: `#2563EB`
- `backend/`  Symfony + API Platform
- `frontend/` React Native + Expo mobile app
- `docker-compose.yml` Postgres, Redis, Mailpit for local development

See `AGENTS.md` for the full project guide.
